# 5Tech Store

A modern, responsive product showcase website for tech accessories and gaming gear. Customers can browse products, view specs, and contact the store through Telegram after taking a screenshot of the product they are interested in.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Database + Storage
- Vercel deployment

## Features

- Home, product listing, product detail, about, contact, and admin pages
- Search, category filtering, and pagination
- Dark/light mode
- Loading skeletons
- SEO metadata, robots, and sitemap
- Supabase-ready API routes for products, categories, and image upload
- Fallback seed data so the site still renders before Supabase is connected

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Copy environment variables:

```bash
cp .env.example .env.local
```

3. Start development:

```bash
npm run dev
```

## Supabase setup

Create these inside Supabase:

1. A new project
2. The `categories` table
3. The `products` table
4. The `product-images` storage bucket
5. Public read policies for categories, products, and storage
6. Service-role management policies used by the API routes

Use:

- [supabase/schema.sql](./supabase/schema.sql)
- [supabase/storage.sql](./supabase/storage.sql)
- [SUPABASE_SETUP.md](./SUPABASE_SETUP.md)

## Vercel deployment

1. Push this project to GitHub
2. Import the repository into Vercel
3. Add the environment variables from `.env.example`
4. Deploy

The public site link will be generated by Vercel after deployment.
